About PLAYA

PLAYA is a community token inspired by tourism, the sea and vacations. It is a standard ERC-20 contract built on OpenZeppelin with a fixed supply: there is no function to create more tokens after deployment, and the contract has no owner or admin functions.

PLAYA is an experimental project. For now it does not offer a specific utility or any promise of future use. Its purpose is to explore how a community token can represent a shared identity around the sea and travel.

What PLAYA is, and is not

  • It is a fixed-supply ERC-20 token on Base, with open and verified source code.
  • It is a community and cultural experiment around beach, travel and vacation themes.
  • It is not an investment product, a security, or a promise of profit.
  • It has no guaranteed value, utility or price.

FAQ

Can more PLAYA be created?

No. The contract mints the full 1,000,000,000 supply once, at deployment, and has no function to mint more. You can check this in the verified code on BaseScan.

Who controls the contract?

Nobody. It is a standard ERC-20 with no owner or admin functions, so no one can pause transfers, blacklist wallets or change the rules.

How do I add PLAYA to my wallet?

Use the “Add PLAYA to MetaMask” button, or add it manually: choose the Base network, go to Tokens, Import tokens and paste the contract address shown on this page.

Where can I trade PLAYA?

Currently only through the Uniswap v2 pool on Base. Liquidity is very small, so trades can move the price a lot. Always check the contract address first.

Is PLAYA an investment?

No. It is an experimental community token with no promised value or utility. Only use money you can afford to lose.

Which are the official channels?

This website and contacto@playatoken.com. The team will never ask you for your seed phrase or private keys, or for money by message.
