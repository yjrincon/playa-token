Acerca de PLAYA

PLAYA es un proyecto experimental creado para aprender sobre contratos inteligentes, tokens ERC-20 y aplicaciones Web3. Esta página presenta el proyecto y documenta su desarrollo.

El objetivo actual es educativo: explorar el funcionamiento de un token en una red de pruebas.

Importante: PLAYA está desplegado en Base Sepolia, una red de pruebas. Los tokens de esta red no representan por sí mismos dinero, propiedad ni derechos financieros, y no se afirma que tengan valor de mercado. Esta página es informativa y no es una oferta de inversión.
